# AIResearch2 – Agent + Website Component Kit

این مخزن برای ادغام ایجنت ساخت وب‌سایت و Website Component Kit آماده شده است.

## وضعیت فعلی

- شاخه بررسی: `integration/agent-wck-fa`
- گزارش بررسی فنی: [INTEGRATION_REVIEW.md](./INTEGRATION_REVIEW.md)
- نسخه کیت بررسی‌شده: Website Component Kit 0.4.0
- تست‌های کیت: 31 passed
- تست‌های ایجنت: 34 passed، 3 failed (دو تست قدیمیِ catalog و یک تست نیازمند نصب Django)

**توجه:** فایل‌های منبع دو ZIP هنوز به‌صورت کامل در این مخزن قرار نگرفته‌اند؛ این شاخه فعلاً شامل گزارش بررسی و راهنمای اولیه است. ادغام کد و انتشار نسخه فارسی تا زمان انتقال کامل فایل‌های منبع و اجرای تست‌های نهایی انجام‌شده محسوب نمی‌شود.

## هدف نسخه ادغام‌شده

- رابط ساخت سایت و پیام‌های پیشرفت/خطا به زبان فارسی
- خروجی پیش‌فرض فارسی با `fa-IR` و `dir="rtl"`
- استفاده از Page Recipeهای فارسی WCK برای فروشگاه، پزشکی و سایر دسته‌ها
- انتخاب تم فارسی به‌صورت پیش‌فرض و امکان انتخاب زبان/تم انگلیسی
- حفظ جداسازی ایجنت و کیت مستقل، با بارگذاری تنبل metadata و templateها
- جلوگیری از بازنویسی فایل‌های پروژه و حفظ اعتبارسنجی، snapshot و QA

برای جزئیات فنی و موانع فعلی، گزارش بررسی را ببینید.
