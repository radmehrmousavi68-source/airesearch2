## اصلاحات نسخه کاری

- انتخاب Page Recipe بر اساس نوع سایت، از جمله فروشگاه عمومی و پزشکی
- انتخاب تم فارسی Recipe به‌جای تم پیش‌فرض نامرتبط
- تولید `lang="fa-IR"` و `dir="rtl"` برای Recipeهای فارسی
- افزودن محتوای نمونه فارسی برای بخش‌های اصلی فروشگاه
- اصلاح تست‌های وابسته به فهرست ثابت قدیمی کامپوننت‌ها
- افزودن تست سازگاری تنظیمات تمام Recipeهای Django
